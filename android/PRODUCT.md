# Ruqenai for Android

<!-- impeccable:product-schema 1 -->

## Platform

android

## Product Purpose

Native mobile chat for thinking, writing, and coding with DeepSeek. The user requested a full visual redesign similar to the existing Ruqenai desktop app, including text shimmers and animations.

## Capabilities and Constraints

Java Android Views, minimum Android 8. Local API-key setup, streamed replies, two DeepSeek model choices, saved on-device conversations, rename/pin/delete actions, light/dark appearance, and file/photo/camera selection. Attachment requests currently include filenames only. No account sync or desktop pairing is wired into this UI. Successful provider responses require a valid user-supplied API key.

## Brand Commitments

Preserve Ruqenai's name and logo; adapt the desktop Ink/Porcelain appearance to native Android touch navigation. Keep the standalone chat behavior.

## Accessibility

Support system text scaling, 48dp touch targets, named icon controls, scrollable content, and disabled system animations.
